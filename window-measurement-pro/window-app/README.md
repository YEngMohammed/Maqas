# نظام إدارة ومقاسات الشبابيك

تطبيق ويب متعدد الصفحات لإدارة مشاريع الشبابيك ومقاساتها، يعمل بالكامل على المتصفح ويخزّن البيانات محلياً (Local Storage) — بدون أي خادم (backend) أو قاعدة بيانات خارجية.

## طريقة التشغيل
1. فك ضغط المجلد بالكامل في مكان واحد (حافظ على تجميع `css/` و `js/` و `lib/` مع ملفات `.html`).
2. افتح `index.html` مباشرة بأي متصفح حديث (Chrome / Edge / Firefox).
3. كل البيانات (المشاريع، المقاسات، النماذج، الأنواع) تُحفظ تلقائياً في متصفحك على نفس الجهاز.

## ملاحظة مهمة حول التشغيل الأوفلاين 100%
التطبيق نفسه (الواجهات والمنطق والتخزين) يعمل بالكامل بدون إنترنت فور فتحه.
الاستثناء الوحيد هو **مكتبات التصدير** (Excel وPDF) التي يستخدمها زر "تصدير Excel" و"تصدير PDF":
- `xlsx.full.min.js` (لتصدير Excel)
- `html2pdf.bundle.min.js` (لتصدير PDF)

هذه المكتبات مرجعة حالياً من الإنترنت (CDN) كحل احتياطي، لأن بيئة الإنشاء الحالية لا تملك اتصالاً بالإنترنت لتنزيلها وحزمها معك مباشرة. لتفعيل التصدير أوفلاين 100٪:
1. نزّل الملفين التاليين من أي جهاز متصل بالإنترنت:
   - `https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js`
   - `https://cdnjs.cloudflare.com/ajax/libs/html2pdf.js/0.10.1/html2pdf.bundle.min.js`
2. ضعهما داخل مجلد `lib/` بنفس الاسمين تماماً.
3. بعدها سيستخدم التطبيق النسختين المحليتين تلقائياً (تم برمجة الصفحة لتفضيل الملف المحلي، والرجوع لل CDN فقط إذا كان الملف المحلي غير موجود).

باقي التطبيق (إضافة/تعديل/حذف المشاريع والمقاسات والنماذج، البحث، الوضع الليلي، النسخ الاحتياطي JSON) لا يحتاج إنترنت إطلاقاً في أي وقت.

## هيكلية الملفات
```
window-app/
├── index.html      # قائمة المشاريع
├── editor.html      # محرر المقاسات (11 حقل + جدول)
├── settings.html     # الإعدادات: المظهر / الأنواع / النماذج / النسخ الاحتياطي
├── css/
│   ├── main.css
│   └── components.css
├── js/
│   ├── core.js        # التوجيه، الوضع الليلي/النهاري، أدوات مشتركة
│   ├── storage.js      # طبقة التخزين المحلي (LocalStorage)
│   ├── projects.js      # منطق قائمة المشاريع
│   ├── measurements.js    # منطق محرر المقاسات
│   ├── settings.js      # منطق الإعدادات
│   └── export.js       # محرك تصدير Excel / PDF
└── lib/            # ضع هنا مكتبات xlsx و html2pdf للعمل أوفلاين بالكامل (اختياري)
```

## النسخ الاحتياطي
من صفحة الإعدادات ← تبويب "النسخ الاحتياطي"، يمكنك تنزيل نسخة JSON كاملة من بياناتك، واستيرادها لاحقاً (دمج أو استبدال) — مفيد لنقل البيانات بين الأجهزة أو كخط رجعة.
